✎ 격자에서 바로 수정

다음 미작성 →
설명이 아직 비어 있는 사진만 골라 차례로 열어줍니다. 빈 곳을 채울 때 씁니다.
↻ 다시 빌드
지금까지 고친 내용으로 이 페이지(index.html)와 LOG.md 를 다시 만듭니다. 설명만 고친 거라면 자동으로 반영되니 누를 일이 거의 없고, 장소·날짜를 바꿔서 사진이 다른 날짜·장소로 묶여야 할 때 누르면 됩니다.
📂 새 사진 정리
staging/ 폴더에 새로 넣은 사진·영상을 한 번에 처리합니다: 이미 있는 사진이면 걸러내고 → 촬영일시·GPS를 읽어 → 지명을 붙이고 → organized/날짜__장소/ 로 옮기고 → 썸네일을 만들고 → 페이지를 다시 만듭니다. 사진이 많으면 몇 분 걸립니다.
⇩ 수정본 내보내기
서버 없이 파일을 직접 열었을 때(file://)는 고친 내용이 파일에 못 들어가고 브라우저에만 쌓입니다. 그걸 pending_edits.json 으로 내려받는 버튼입니다. 받은 파일을 data/ 에 넣고 jiho.py merge 를 실행하면 반영됩니다. 서버로 열었다면 저장이 곧바로 파일에 들어가므로 쓸 일이 없습니다.
사진 크게 보기 → 장소 일괄
그 사진의 GPS 좌표가 같은 사진 전부의 장소 이름을 한 번에 바꿉니다. 예를 들어 자동으로 "서울 마포구 아현동"이라고 붙은 곳을 "우리 집"으로 바꾸면, 같은 좌표에서 찍힌 사진이 모두 "우리 집"이 됩니다. GPS가 없는 사진에는 쓸 수 없고, 그럴 땐 날짜 카드의 '이 날 장소 일괄 지정'을 쓰세요. (옆의 저장은 지금 보고 있는 사진 하나만 바꿉니다.)
검색창
