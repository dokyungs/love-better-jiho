## 1. 컷 고르기 — 제일 중요, 이것만 되면 나머지는 자동

**같이 · 각자 1시간 · D-9(7/28)까지**

갤러리에서 **[🎬 영상 태깅]** 을 누르면 아직 안 고른 사진부터 차례로 열립니다.
사진 한 장마다 **키보드로** 누르면 됩니다.

| 키 | 뜻 |
|---|---|
| `1` `2` `3` | ✕ 안 씀 / · 보통 / ★ 꼭 넣을 것 |
| `A` `S` `D` `F` … | 같이 나온 사람 (엄마·아빠·할머니…) |
| 사진 클릭 | 지호 얼굴 위치 — **가로/세로로 자를 때 얼굴이 안 잘리게** |
| `P` | 🔒 비공개 (하객 앞에 띄우면 안 되는 컷) |
| `N` | 다음 사진 |

**분담 (겹치지 않게):**
- [ ] **아빠** — 2025년 8월 ~ 2026년 1월 (위쪽 월 버튼으로 이동)
- [ ] **엄마** — 2026년 2월 ~ 6월

**요령**
- 전부 고를 필요 없습니다. `2`(보통)를 기본으로 빠르게 넘기고, 정말 좋은 것만 `3`(★).
- ★ 는 **60~80장** 이 적당합니다. 너무 많으면 5분에 안 들어갑니다.
- 인물 태그는 **"지호 말고 누가 같이 나왔나"** 만. 지호는 다 나오니 목록에 없습니다.
- 얼굴 위치는 **★ 준 컷만** 찍어도 충분합니다.
